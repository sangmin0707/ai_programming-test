### scores_2026.csv행 수

### scores_2026.csv열 설명
| 열 | 뜻 | 자료형 | 허용 범위 |
|---|---|---|---|
| 학번 | 학생 번호 | 문자 | 8자리 숫자 |
| 이름 | 학생 이름 | 문자 | |
| 반 | 소속 반 | 문자 | 1반, 2반 |
| 과목 | 응시 과목 | 문자 | 수학, 영어, 프로그래밍 |
| 점수 | 그 과목의 점수 | 정수 | 0 이상 100 이하 |

### 정제 순서와 행 수 변화
| 순서 | 처리 | 행 수 |
|---|---|---|
| 1 | 점수가 빈 행 삭제 | 114 → 108 |
| 2 | 반·과목 뒤의 공백 제거 (값만 고치고 행은 지우지 않음) | 108 → 108 |
| 3 | 모든 열이 같은 중복 행은 뒤의 행 삭제 | 108 → 104 |
| 4 | 점수가 0~100 밖인 행 삭제 | 104 → 100 |

###  빈 칸을 어떻게 처리했는지와 그 이유
점수가 빈 행 6개는 채우지 않고 삭제했다.
평균 같은 임의의 값으로 채우면 그 값에 따라 반별 평균과 분산이 크게 달라질 수 있기 때문이다.
빈 칸은 전체 114행 중 6행으로 적어서, 삭제해도 결과에 미치는 영향이 작다고 판단했다.
